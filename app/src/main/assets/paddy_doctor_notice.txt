AgriBicara — model deteksi penyakit padi (Fase 4)

Model klasifikasi penyakit padi dilatih menggunakan dataset "Paddy Doctor".

  Paddy Doctor: A Visual Image Dataset for Automated Paddy Disease
  Classification and Benchmarking.
  Petchiammal A, Briskline Kiruba S, D. Murugan, Pandarasamy Arjunan.
  https://github.com/paddydoc/paddy-doctor-dataset
  https://paddydoc.github.io

Dataset dilisensikan di bawah Apache License, Version 2.0. Salinan lisensi:
  http://www.apache.org/licenses/LICENSE-2.0

Atribusi ini WAJIB ikut disertakan pada distribusi aplikasi yang memuat model
turunan dari dataset tersebut (mis. di layar "Tentang / Lisensi pihak ketiga"
aplikasi, dan di listing Play Store bila relevan).
